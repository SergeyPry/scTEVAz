# single-cell Tissue Expression Values Aggregator in zebrafish - scTEVAz

## Loading raw data and sources

The following sections comment and describe the data sources and code needed to generate processed files for this project. In the following sections, we provide the information on the original sources of the data and describe the initial steps of preparing these datasets for usage in the later sections of the project.

### Daniocell

https://daniocell.nichd.nih.gov/

The processed Seurat (v4) object:
Daniocell2023_SeuratV4.rds (Seurat object)
cluster_annotations.csv (Cluster annotations)
daniocell_load.R (R script to load object and annotations, with function to regenerate tissue-specific cropped objects)
